## Rationale
User-reported defect: a binary search snippet rendered as a degenerate 2-node graph (entry -> terminal). Root causes found at every pipeline stage: (1) StructuralAnalysis reduced control flow to bare branch COUNTS with no conditions/order/calls; (2) the generation prompt gave the LLM nothing to reconstruct shape from; (3) validateGraph only checked referential integrity, so lazy graphs passed and never triggered healing; (4) the live executor in backend/src/index.ts generated ONCE without the heal loop; (5) scorers actually rewarded any connected graph with entry+terminal.
